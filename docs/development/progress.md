# 实现进度（2026-09-29）

已在根目录 Spring Boot 应用中实现首个人员闭环：登录 → 人工建档/PENDING → 管理员决定准入 → 人工赋标 → 抑制/追加依据恢复 → 事实与关系历史。

## 已完成

- 项目合并为根目录单一 Spring Boot JAR，应用和模型测试统一放入 `src/test/java`；Foundry 独立构建并以 Maven 制品依赖。
- Domain Pack 移至 `src/main/resources/domain-pack`，前端源码位于 `web/`；根 Maven 构建自动生成并打包静态资源，默认从 JAR 读取领域定义。

- 独立 JDBC-H2 文件存储及连接生命周期；显式一次性合成目录初始化，不创建虚构人员，不改旧库。
- Spring Security 账号/会话/CSRF；密码为 BCrypt 哈希。基础档案维护、标签维护、查看、管理员分权，组织集合由服务器配置。
- Mirror 命令服务选用五个已有 Pack Action，规范输入/幂等键/贡献身份；通过 Foundry `ActionExecutor` 注入事务授权策略，覆盖参数、效果与重放。
- 普通业务查询按组织过滤并剔除敏感属性及历史敏感值；准入、目录、来源贡献时间与人工抑制共同决定当前标签有效性。
- REST/GraphQL 通用接口与诊断仅管理员可读；通用写入口拒绝，避免旁路。对象浏览、关系导航、对象历史和模型/审计/outbox 诊断保留。
- 人员列表、筛选/分页、详情、业务表单、变更记录、错误与冲突提示、提交防重，以及移动布局。
- 人员详情直达对象关系，按全部关系类型双向读取；支持逐层浏览、路径返回、类型筛选、分页、已结束关系与独立的关系历史。页面用词已按原文核对并简化，见[页面术语](../business/ui-terminology.md)。
- 对象浏览增加业务描述：任职说明人员/单位/岗位，标签与依据显示实际名称和生效含义；侧栏、标题和路径保持一致。关联称呼按当前对象视角表达，原始类型、箭头及 ID 折叠在技术详情中。
- 按 Excel 数据形态生成可选参考样例：15名人员、18个组织、10个岗位、22个标签及7组标签关联；准入和标签场景明确为合成，初始化回执与数据同事务，不覆盖已有修改。见[参考样本初始化](reference-data.md)。

本轮无须修改 Foundry 子模块或增加领域对象/Action；使用已有 SPI 与 Action 授权扩展。后续其他闭环需要的底座能力独立评估。

## 实施边界

- 这是首个人员闭环的本地可用实现，不是全部业务或正式部署验收。
- 本地账号文件修改需要重启，旧会话失效；没有账号管理页面、热更新或统一身份源。
- 合成目录为显式验收夹具。正式组织/标签目录的维护发布仍需受控业务入口；不能把初始化事务用作日常业务 CRUD。
- H2 用于本地持久化验证；国产目标数据库、规模性能及跨读取一致快照尚未验收。
- outbox 已持久保存但无实际投递器；自动规则、专项、提醒、外部渠道及旧库迁移未实现。
- 原文业务分歧未因本闭环实现而全部定案；准入决定保守限定为管理员，普通业务账号不能标记非对象。
