# Foundry通用治理首批修复

日期：2026-09-27。本文为F1阶段记录，后续时间语义进展见[时间修复报告](temporal-repair.md)。Foundry修复提交：`f779240577ad56c66461be1338c2367b6edf8e38`。按照[上游覆盖审计](foundry-vs-open-foundry.md)推进，完整目标保留，未改变政务业务归属。

## 已实现

- ODL显式Action权限保留到编译元数据及摘要；API只执行可信注册的类型/manifest，默认拒绝未注册、篡改或无权限声明的动作。
- 执行及回放检查主体/租户、Action级和逐对象权限；对象ID由当前租户重新解析，禁止客户端传入对象快照；关系删除检查关系与两端对象。CEL使用真实对象字段，保留actor/params/now防止覆盖。
- 通用对象单查、列表、历史采用字段白名单；默认隐藏敏感和未声明字段，显式角色策略控制敏感查看。GraphQL普通属性正确读取，受限字段可为空而不使整对象报错。
- 内存幂等按租户/主体/动作隔离，配置及参数摘要绑定，并发请求原子重放；不同请求或配置复用键拒绝，权限撤销后不返回旧结果。明确仅单进程内存保证，持久回执仍待完成。
- OpenFGA标准Check路径和body模型参数修正；用户和资源编码均带租户，拒绝异常响应，设置超时。仅HTTP stub验证，真实服务与元组迁移未执行。
- Action YAML未支持的sideEffects/rollback等明确拒绝，不再静默丢弃后宣称加载成功。完整效果兼容仍待实现。
