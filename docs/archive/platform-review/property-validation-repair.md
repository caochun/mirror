# Foundry属性约束与并发完整性修复

日期：2026-09-28。Foundry提交：`a80c86a99d5a15b2e10fd431ae94e03a5b079f17`。目标保持为完整重制Java Foundry核心并覆盖固定上游v0.3.0；本轮是其中一个已验证阶段。

## 本轮成果

- 对象与关系的新建/更新统一校验必填、未知属性、标量类型、枚举、列表元素、主键与不可变字段。补丁合并后检查必填，区分null与省略。
- 唯一约束按租户/类型/字段执行，支持更新释放、软删除释放、事务回滚和时间值规范化。数据库租户行锁保护多Provider竞争；唯一索引不因被拒绝的更新提前释放占用。
- JDBC数据库失败后事务只能回滚，防止对象写入成功但历史写入失败时提交半份状态。单连接池和并发约束有专门测试。
- 深复制属性列表/JSON，禁止外部修改内存对象及历史；修复内存组合键可因分隔符造成跨租户串用的问题。
- ODL保留枚举与列表元素非空标记；Schema摘要包括枚举，删除枚举成员、改变字段类型或收紧约束正确标记为破坏性变化。
- 同步对相同属性不重复提交更新，避免重传不可变主键；成功计数在事务提交后更新。

## 验证

Foundry完整110项、Mirror根reactor完整220项测试通过，0失败/错误/跳过；随后细化旧重复值的逐项修复语义，相关24项属性/并发测试再次通过。新增26项：18个双Provider属性契约用例、6个JDBC并发/回滚/旧重复修复/单连接池用例、2个Schema演进用例。

独立探针见[最新观察](foundry-audit-current.json)：两Provider对缺必填、类型错误、重复唯一值和不可变修改均拒绝；String→Int迁移从COMPATIBLE改为BREAKING。此前治理和时间查询修复仍成立。

这些结果来自memory/H2及HTTP测试，不能替代实际国产库、真实OpenFGA和生产性能验收。没有重新打包或启动Mirror服务；前端未变更，本轮未重复运行浏览器套件。

## 下游兼容
