# Foundry组合Pack、资产装配与种子初始化

日期：2026-09-28。Foundry提交：`e3104da`。完整上游核心覆盖目标继续。

## 已实现

新增loadBundle，先收集各Pack声明及引用，再验证namespace/version和依赖图，最后统一编译接口、枚举、对象、关系与动作。组合结果包含类型所有者及稳定内容摘要；缺失/循环依赖、未声明引用、同名冲突和源版本漂移明确拒绝。单Pack load及旧loadAll保留独立编译语义。

标准资产现在进入加载结果：FGA源文件、约定字段权限、种子、连接器声明、capabilities及扩展元数据。字段策略可由ApplicationService.fromBundle自动装配；按上游角色名匹配存储字段，虚拟关系保持独立可见性和授权。路径越界、Pack外符号链接、缺失文件及重复YAML键均拒绝。

PackSeeder显式指定tenant/actor后，通过同一事务创建种子及历史、回执、审计和outbox，支持跨文件前向引用。稳定回执保证重放不覆盖业务修改，新增文件可使用原引用，原种子定义变化要求迁移。回滚与并发不会留下部分初始化；跨租户事件/审计ID隔离。

## 验证

常规根reactor **396项**，其中Foundry **286项**，全部通过，无失败/错误/跳过。新增18项覆盖组合、依赖和版本门禁、资产边界、事务种子、重放保留修改、租户隔离、并发及H2文件恢复；随后Pack边界补查通过。

真实OpenFGA **9项集成**也全部通过，现已使用组合模型、自动种子和加载的字段策略运行原始Library：验证借还、角色字段隐藏、虚拟关系导航、撤权和租户隔离。加载的DSL与官方转换的JSON模型核对SHA，测试store已清空，临时服务已关闭。

独立审计探针同样使用loadBundle及种子回执，确认原有属性、时间、权限、恢复能力无回退。Mirror现有业务Pack和服务测试通过；未改动实际业务数据库或重建运行中的JAR。
