# Foundry LAZY计算字段

日期：2026-09-28。Foundry提交：`9b1dcc1`。完整上游覆盖目标继续。

## 本次实现

ODL不再丢弃计算字段，保留函数、参数、缓存策略、结果类型及保护标记，并接通接口继承、Schema摘要、差异及Pack依赖检查。未知函数、错误方向、结果类型和不可执行策略明确拒绝；计算字段不能写入普通属性。

覆盖固定上游实际实现的LAZY/countLinks：每次读取重新计算活动关系条数，不被第一页100条截断，也不把同一端点的多条关系合并为一个。内部可信求值器提供原始总数，公开API按可见关系及字段策略收敛。

对象、列表、GraphQL接口/字段和REST单字段读取均可使用计算结果。双时间读取用同一时点查询关系和端点；原始历史不补造计算值，对象版本及存储属性不会因求值改变。未声明计算字段的旧模型保持原摘要编码。

## 范围与剩余项

固定上游v0.3.0也未实现EAGER/TTL；本轮不把拒绝这些配置算作支持。公开值可能低于内部总数，这是为了不通过统计泄露隐藏关系的明确策略。

SQL聚合下推、批量授权、跨多次读取的一致快照、完整时间HTTP参数和Action计算依赖仍待完成；结构值、自定义标量、查询、注册表、同步等继续按总计划推进。见[ADR-0015](../../../foundry/spec/adr/0015-lazy-computed-fields.md)。没有重建运行JAR或改动业务数据库。
