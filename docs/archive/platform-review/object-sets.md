# Foundry ObjectSet保存查询

日期：2026-09-28。Foundry提交：`0aa60b0`。完整核心覆盖目标继续。

## 本阶段

新增ObjectSet定义和存储SPI，提供内存/JDBC的创建、读取、按名查找、列表、部分更新和删除。身份/创建者由请求上下文确定，同租户共享，修改与删除仅限创建者；增加revision/CAS和事务内补丁合并，定义可持久恢复。

保存的是筛选、排序和可选聚合，不是成员快照。执行时按当前调用者的对象/字段权限计算，公开定义不会授予对象访问权；聚合同时应用集合筛选与聚合筛选。共享定义包含不可见字段条件时，不向其他用户泄露条件值。执行中取消共享、删除或修改定义会阻止旧结果返回。

REST提供object-sets管理、execute与aggregate入口；GraphQL提供上游CRUD形状及动态执行/聚合扩展。通过构造器显式注入ObjectSetStore，未配置时返回明确错误。支持上游SPI筛选形状及_id主键别名，非法/不支持字段和操作符不会静默忽略。
