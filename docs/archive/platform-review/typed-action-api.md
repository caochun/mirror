# Foundry类型化Action API与参数校验

日期：2026-09-28。Foundry提交：`3717339`。完整核心覆盖目标继续。

## 已实现

参数校验可绑定可信Schema，支持枚举、平台标量及递归列表非空规则。枚举和Duration/URI/GeoPoint不再被误当成对象引用；对象仍只从当前租户的ID解析，不接收客户端快照。未知类型及无效声明在编译或执行前拒绝。

GraphQL默认生成ActionNameInput/Result，保留枚举、标量和列表类型；输出包含状态、错误及affectedObjects的typeName/id/changeType。前置条件失败带声明中的说明，旧回执缺少变更依据时返回UNKNOWN。回执的返回目标与access/journal不一致时拒绝，不重新执行业务。

旧字符串输入保留为显式createLegacy/LEGACY_JSON模式及对应SDL生成方式。默认签名切换需要调用方更新查询；旧信封不额外输出新的changes成员。REST新增结构化变更信息，原请求摘要和回执格式继续沿用。

## 验证

完整常规根reactor **430项**，其中Foundry **320项**，全部通过，无失败/错误/跳过。新增17项覆盖枚举、自定义标量、嵌套列表、JSON字面量与变量、显式null、非法输入无写入、幂等、无参数动作、结果类型、旧JSON入口、未知类型及命名冲突。随后14项授权测试补查旧/损坏/目标不一致的回执也通过。

独立探针确认非法枚举在写入前拒绝，合法类型化请求返回UPDATED并正确保存状态；原有属性、时间、权限、Pack、计算及恢复验证保持通过。没有重建运行中的服务JAR或更改业务数据库。

## 剩余范围

结构值与接口型参数、完整过滤/排序/聚合、批量/订阅API、注册表、同步及生产身份/数据库集成仍待完成。参数校验共享规则，但幂等键仍绑定具体请求表示，不自动合并不同数值/时间表示。完整兼容说明见[ADR-0016](../../../foundry/spec/adr/0016-typed-action-api.md)。
