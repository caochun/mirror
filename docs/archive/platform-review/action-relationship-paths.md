# Foundry Action关系路径与读取证据

日期：2026-09-28。Foundry提交：`a9db3de`。完整核心覆盖目标继续。

## 已完成的能力

上游preResolveLinkPaths/resolveTarget支持的关系路径已接入Java：例如person.unit.region.name可用于CEL前置条件、效果值、沿路径更新目标、创建关系端点、筛选删除及通知插值。

解析发生在业务事务内，支持声明的正反向、集合、关系属性和已结束关系。旧输入的相关路径在效果前捕获，新建对象别名在实际使用时解析；关系后来结束不改变本次动作已捕获的上下文。

读取权限独立于写入权限。源对象、关系字段、关系及端点按配置模式检查权限，受控主体还检查Consent。沿路径读取某个对象不会自动取得修改权；严格模式创建关系须检查已有端点的Action权限，本体模式保留上游端点viewer规则。

回执/continuation保存原关系身份、字段声明和路径证据，并以摘要检测丢失/截断/修改。重放及续执行检查原来读取过的实体，而不是重新沿今天的关系取值；通知数据保持首次提交时的值。

## 上游差异与边界

未照搬上游事务外读取和多关系取第一条：单值歧义拒绝，声明集合保持集合。历史字段指当前保存的已结束关系身份，不等同任意双时间快照。

路径发现仍为静态点路径扫描；CEL局部变量或动态下标后的进一步关系跳转、完整表达式依赖图尚未实现。上游接口型Action参数经源码确认只是透传，并非已完成的多态对象解析；该模型能力继续留在未完成计划中。

旧动作不涉及关系路径时仍兼容；涉及路径却缺少读取证据的旧回执拒绝重放/续执行，不能根据现有关系补造过去的依据。提交前拒绝回滚命令；提交后的投递遭拒保留已提交事实和任务，不伪装为业务回滚。外部权限检查也不是与数据库提交共锁的撤权屏障。
