# 核心价值大屏设计说明

大屏不是把业务页面缩小后堆在一起，而是以“对象—关系—画像—提醒—闭环”组织一条监督价值链。

## 视觉层级

顶部使用深色标题区，固定显示“政务系统对象库 · 核心价值总览”和“演示数据 / Mock”。第一屏先给出五个总量指标；中部左右并排放对象关系和标签画像；下部放提醒闭环、数据质量和可追溯明细。

颜色只表达业务状态：蓝色代表对象和关系，紫色代表标签画像，青色代表送达，绿色代表已读，橙色代表待治理，红色代表逾期或异常。每个颜色都配文字，不能只靠颜色传达含义。

## 指标口径

- 有效对象：当前状态为有效且不是非对象账号的人员去重数。
- 标签覆盖率：至少拥有一个当前有效标签的有效对象数 / 有效对象数。
- 送达率：送达成功人数 / 已提交人数。
- 阅读率：当前最新版本已读人数 / 送达成功人数，并在卡片中直接显示分母。
- 逾期未读：超过该接收人的阅读时限且当前版本仍未阅读的人数。
- 关联异常：身份、当前组织或档案关联无法唯一确定的对象数；不等于对象被删除。

## 下钻方式

大屏第一版只需提供可复现的演示下钻：点击“逾期未读”显示单位和人员清单；点击标签排行显示标签覆盖人员；点击组织分布显示该组织对象摘要。真实系统接入时，这些入口替换为带组织范围和统计时间条件的业务 API。

## Mock 边界

Mock 数据用于验证视觉层级、指标口径和业务叙事，不代表真实人数、单位、标签或送达结果。页面、README 和部署说明均显示该边界。任何真实生产展示必须由后端查询投影和权限范围重新计算，不能直接复用前端 Mock 数组。
